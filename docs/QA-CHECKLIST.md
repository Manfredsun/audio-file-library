# QA 驗收清單

此為內部 QA 預覽，使用獨立資料庫，尚未核准公開發布。開啟 Audio File Library Beta。

## 實機流程

先將少量音效複製到臨時測試資料夾，再將該資料夾加入 QA App。

- 索引完成後，搜尋能找到預期音效。
- 選取並預覽 A，再預覽 B，A 會停止；波形與目前播放音效一致。
- 修改顯示名稱、分類、標籤及備註後，重新掃描或重讀路徑，人工編輯仍保留；人工清空風格／材質也保持空白。
- 快速連續重新掃描，不會把仍存在的音效標為遺失。
- 拖入 Logic Pro 能正常使用；來源是原始音檔路徑。
- 透過命名預覽建立少量整理連結，再由整理紀錄撤銷；原始音檔保留。請只對臨時測試資料夾執行這一步。
- QA 的人工編輯留在 QA 資料庫，不會自動移入正式版本。

## 分類抽樣

人工試聽 30–50 筆代表性素材，涵蓋不同類別與信心程度，特別記錄高信心卻錯誤的結果。
「未知／待複查」是合法結果，不以分類覆蓋率當作品質證明。

回覆摘要即可，不需要提供私人音檔、素材檔名或完整路徑：

- 抽樣總數：
- 可接受的建議數：
- 錯誤建議數：
- 未知／待複查數：
- 高信心錯誤數與現象：
- 實機流程通過／未通過，以及具體問題：

只有使用者親自確認後，才能勾選任務卡的兩項人工驗收。程式碼審查及單元測試不會代替這個判斷。

## 外觀與語言（beta.2）

- 齒輪／⌘,可開啟設定，淺色與深色即時切換；搜尋、選取與編輯草稿保持。
- 跟隨系統時會隨macOS外觀變更；重啟後設定保留。
- 選繁體中文或English後目前介面不變，下次開啟完整套用，跟隨系統可還原系統語言。
- 在兩種語言與兩種外觀下檢查清單、檢查面板、波形、選單、提示及最小視窗；窄篩選列可水平捲動。
- 中文內建名稱可搜尋，同一名稱的中英文結果相同；分類識別、人工內容與整理目的路徑均不變。
