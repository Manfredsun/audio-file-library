# 1.0.2-beta.2 候選變更

- 新增淺色、深色與跟隨系統，切換不重建音色庫、播放及背景服務。
- 新增繁體中文與English，語言儲存後於下次開啟套用，含原生選單與資料夾視窗。
- 新增內建分類、風格、材質顯示翻譯及中英文名稱搜尋，原始值與人工資料不變。
- 新增一般設定（齒輪／⌘,），分析與備份移到「分析」選單。
- 改善最窄欄位的篩選列與英文數量顯示。

- 撤銷整理核對實際檔案身分，保留替換檔案、資料夾及最後一份硬連結；逐筆記錄結果並支援失敗重試。
- 原子移入私有暫存位置後再次核對身分，防止檢查與刪除之間的名稱替換；無法安全恢復時保留檔案並回報位置。
- 保護重讀／回填期間的人工作業，人工清空風格與材質也會保留來源。
- 音色庫搬移後更新既有紀錄路徑，保留人工 metadata、分頁與波形；衝突時回滾。
- 掃描略過音色庫根目錄的 `_Organized`，避免重複匯入產生的硬連結；保留不跟隨庫外連結的行為。
- 每次掃描採唯一識別，避免時間精度造成已刪除音檔未被標成遺失。
- 同庫掃描以資料庫 ownership 保護，舊掃描與重新連結前的背景工作不能覆寫新結果。
- 整理僅取得已知路徑的通行權，避免不必要地讀取音色庫祖先目錄。
- 備份失敗時停止批次修改；背景寫入失敗會明確回報。
- 固定 GRDB 版本，補授權文件、公開來源檢查與 macOS 驗證流程。

App 版本 1.0.2，build 4。此文件是候選變更清單；是否可發布以 RELEASE-STATUS 為準。
