# Project orientation

Use ROADMAP.md, AGENTS.md, docs/HANDOFF.md, and harness/LOOP.md.

Analysis uses acoustic measurements and literal path evidence; there is no external model dependency. Manual metadata and original audio are protected. Offline libraries retain metadata.

This is a sanitized source snapshot. Private development history, databases, diagnostic reports, and personal audio libraries are intentionally not included. See docs/RELEASE-STATUS.md for verification still required.
